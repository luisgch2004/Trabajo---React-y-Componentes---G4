# Gestión académica (React)

## Opción A: abrir sin instalar nada (más rápida)
1. Haz doble clic en `demo.html`.
2. Se abre en tu navegador (necesita conexión a internet, porque carga React desde un CDN).

## Opción B: proyecto completo con Vite (la que se entrega)
1. Instala Node.js (versión LTS) desde https://nodejs.org
2. Abre una terminal dentro de esta carpeta (`gestion-academica`).
3. Ejecuta:
       npm install
       npm run dev
4. Abre en el navegador la dirección que muestre la terminal (normalmente http://localhost:5173).
5. Para detener el servidor: Ctrl + C en la terminal.

Código a entregar: carpeta `src/` (App.jsx, App.css y components/).
